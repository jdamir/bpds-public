Метод (Event Handler) ProcessReceiptImage

Домен: AID | Сервис: image-processor | Тип: Kafka Consumer

Функциональное назначение

  • English
  • Русский

The asynchronous event handler ProcessReceiptImage is deployed within the image-processor microservice. It acts as a core Receipt Text Context Provider (OCR Context Provider), responsible for pulling task events from Kafka, streaming down paper receipt photos from MinIO object storage, running localized character segmentation, and performing line-by-line text reading.

The method transforms graphical pixels into a structured text dataset. To maintain structural consistency and reuse core perimeter policies, the extracted text is seamlessly pushed into the unified text processing pipeline, triggering the existing censorship-control-worker.

Core Tasks Handled by the Method

  1. Binary Asset Ingestion: Downloads the paper receipt snapshot from the S3 bucket into local execution memory layers via an internal asynchronous Boto3 pipeline.
  2. Optical Character Recognition (OCR Inference): Processes the image matrix using hardware acceleration (GPU/CPU) to segment lines, normalize string layout, and extract text characters.
  3. Perimeter Continuity Delegation: Packages the complete raw text dataset string and forwards it to the core receipt queue under the original trace context.

Interaction Protocol (Event Contract)

  • Method Name: ProcessReceiptImage
  • Message Broker: Apache Kafka
  • Ingress Topic (Subscription): bpds.inventory.in.receipt.image
  • Egress Topic (Publication): bpds.inventory.in.receipt.upload
  • Data Format: application/json

Ingress Message Payload Example

{
  "image_file_url": "https://minio.internal",
  "app_lang": "ru-RU",
  "x_request_id": "trace-ocr-censor-uuid"
}

Асинхронный метод-обработчик (Event Handler) ProcessReceiptImage развернут внутри микросервиса image-processor. Он выполняет архитектурную роль поставщика текстового контента чека (OCR Context Provider) и отвечает за вычитку задач из брокера Kafka, скачивание бинарных файлов фотографий бумажных чеков из объектного хранилища MinIO, построчную сегментацию символов и оптическое распознавание текста.

Метод преобразует графические пиксели в сырой текстовый массив данных. Для сохранения сквозной цепочки обработки и повторного использования контура защиты, извлеченный текст автоматически отправляется в унифицированную текстовую очередь, активируя существующий воркер censorship-control-worker.

Критические задачи метода

  1. Скачивание бинарного ассета: Потоковая загрузка снимка чека из S3-бакета в локальные слои оперативной памяти с помощью асинхронного конвейера Boto3.
  2. Оптическое распознавание символов (OCR Инференс): Обработка матрицы изображения с использованием аппаратного ускорения (GPU/CPU) для локализации строк, нормализации геометрии текста и синтеза символов.
  3. Делегирование в контур фильтрации: Упаковка извлеченного текстового массива в стандартизированное DTO и его публикация в общую текстовую очередь под оригинальным сквозным контекстом трассировки.

Протокол взаимодействия и триггеры (Event Contract)

  • Выходной топик (Publication): bpds.inventory.in.receipt.upload
  • Формат данных: application/json
