Метод execute_intra_day_tick()

Core Simulation Orchestrator: Высокочастотные внутрисуточные такты и пересчет угловой частоты суток

1. Функциональное назначение

Метод execute_intra_day_tick является базовым высокоскоростным итератором и временным метрономом системы (Фаза 1). Он отвечает за дискретизацию моделируемого времени внутри текущих операционных суток. Метод инкрементирует счетчик микро-тактов t, вычисляет текущий виртуальный час сессии и выполняет непрерывный пересчет гармонической угловой частоты моделируемых суток \(\omega\).

2. Математический базис циркадных ритмов

Главная аналитическая ценность метода заключается в динамическом снабжении стохастического процессора временной меткой для плавного волнообразного моделирования поведения агентов (день/ночь) в течение 24 часов.

Умножая текущее время на угловую частоту внутри функции \(\sin(\omega t)\), движок заставляет вероятность интентов плавно расти в пиковые часы активности и падать до минимума в ночные часы симуляции. Полный оборот суточного цикла равен \(2\pi\) радиан. При длительности суток в 24 часа угловая частота \(\omega\) рассчитывается как:

\[\omega = \frac{2\pi}{24} \approx 0.261799 \text{ радиан в час}\]

На каждом такте симуляции текущий час рассчитывается через шаг дискретизации \(\Delta t\):

\[t_{\text{sim\_hour}} = (t \cdot \Delta t) \pmod{24}\]

3. Спецификация метода (ИТ-контракт)

  • Тип вызова: Высокочастотный итератор, внутренний (вызывается каждую итерацию рантайм-цикла).
  • Исполнитель: Core Simulation Orchestrator.

3.1. Входные параметры (Аргументы вызова)

Параметр Тип данных Обязательный Описание
current_tick Integer Да Сквозной счетчик тактов с начала моделируемых суток.
time_delta Float Нет Шаг дискретизации времени в часах. По умолчанию = 0.25 (15 минут).

3.2. Выходные данные (Возвращаемое значение)

Метод возвращает словарь с параметрами виртуального времени текущей итерации:

  • sim_hour (Float): Текущий моделируемый час (в диапазоне от 0.0 до 23.99).
  • harmonic_factor (Float): Текущее значение сунусоиды \(\sin(\omega t)\) для стохастического ядра.

5. Программная реализация метода на Python

import math

class IntraDayTicker:
    def __init__(self, time_delta: float = 0.25):
        self.current_tick = 0
        self.time_delta = time_delta  # 0.25 часа = 15 минут
        self.omega = (2 * math.pi) / 24.0  # ~0.261799 рад/час

    def execute_intra_day_tick(self) -> dict:
        """
        Инкрементирует микро-такт и рассчитывает циклическое
        виртуальное время и гармонический коэффициент суток.
        """
        self.current_tick += 1
        
        # Расчет текущего виртуального часа в сутках
        sim_hour = (self.current_tick * self.time_delta) % 24.0
        
        # Расчет циклического коэффициента для циркадных ритмов
        harmonic_factor = math.sin(self.omega * sim_hour)
        
        return {
            "tick_index": self.current_tick,
            "sim_hour": round(sim_hour, 4),
            "harmonic_factor": round(harmonic_factor, 6)
        }
