  • Frontend Segment: A unified cross-platform mobile client built on Flutter for real-world end-users.
  • Orchestration Loop (Core): A high-performance backend powered by Go (Golang) that manages business logic, session states, and simulator coordination.
  • Simulation Engine: An autonomous Stochastic Simulator driven by an event-based process model.
  • Message Broker Bus: A distributed, event-driven data bus powered by an Apache Kafka Cluster (KRaft) acting as a streaming buffer and fault isolation queue system.
  • AI Compute Module: Isolated worker nodes built on FastAPI that provide non-blocking feature extraction via the Whisper API (Audio VTT) and OCR Core (Vision).
  • Process Analyzer Engine: A specialized computational engine driven by PM4Py (Process Mining Engine) for automated process discovery and conformance checking.
  • Telemetry Platform: A high-throughput analytical data store built on ClickHouse DBMS, aggregating logs and process metrics for comprehensive end-to-end auditing.
