Перейти к чтению документации

  • Фронтенд: Единый кроссплатформенный мобильный клиент на Flutter, для реальных пользователей.
  • Оркестрация (Core): бэкенд на Go (Golang), управляющий бизнес-логикой, сессиями и координацией симуляторов.
  • Движок генерации данных: Автономный Стохастический симулятор с событийной моделью процессов.
  • Шина: Распределенная событийно-ориентированная шина данных на базе Kafka Cluster (KRaft) для передачи событий, в качестве буфера и очередей.
  • AI-модуль: Изолированные воркеры на FastAPI, обеспечивающие извлечение данных через Whisper API (Audio VTT) и OCR Core (Vision).
  • Процессный анализатор: Вычислительный движок на базе PM4Py (Process Mining Engine) для обнаружения графов процессов и анализа соответствия.
  • Платформа телеметрии: Аналитическое хранилище на ClickHouse DBMS, агрегирующее логи и метрики процессов для сквозного аудита.
