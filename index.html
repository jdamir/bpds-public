Платформа спецификации и системного анализа симуляторов бизнес-процессов

Добро пожаловать в единый репозиторий технической спецификации “Цифровые симуляторы бизнес-процессов” (Open-Source / Pet-project). Спецификация обеспечивает сквозной системный анализ, архитектурное проектирование и регистрацию событий бизнес-процессов.

Инфраструктура построена на базе современного распределенного стека:

  • Мобильный клиент: кроссплатформенное приложение на Flutter/React Native.
  • Брокер сообщений: распределенная шина данных на Apache Kafka.
  • Речевые технологии: VTT-сервисы интеграции потокового аудио (Whisper API).

Используйте верхнее меню выбора языка документации, чтобы переключить интерфейс на русский либо английский языки. Для перехода к чтению выберите интересующую вас статью в одном из разделов документации.

Specification and Systems Analysis Platform for Business Process Simulators

Welcome to the unified technical specification repository for “Business Process Digital Simulators” (Open-Source / Pet-project). The specification provides end-to-end systems analysis, architectural design, and logging of business process events.

The infrastructure is built on a modern distributed stack:

  • Mobile Client: Cross-platform application built with React Native.
  • Message Broker: Distributed data bus powered by Apache Kafka.
  • Speech Technologies: VTT services for streaming audio integration (Whisper API).

Use the top documentation language menu to switch the interface between Russian and English. To start reading, select the article you are interested in from one of the documentation sections.
